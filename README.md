# Как всё начиналось?

Страница к стенду о гипотезе математической вселенной Макса Тегмарка
(фестиваль РУДН, 2026). На стенде QR-код ведёт сюда:
https://spectra-crazy.github.io/math-universe/

Один файл `index.html`, без сборки: текст, живая игра «Жизнь»,
«взгляд лягушки и птицы» и вопрос «математику открыли или придумали?».

Авторы стенда: Шепетков Владимир, Караулов Максим.
